1. חיבור הסוכן (חובה)

בלי זה הסוכן לא רואה את הנתונים שלך.

  1. פתח את יצירת טוקן ב-GitHub.
  2. Repository access: Only select repositories ← cfo-data.
  3. Permissions ← Repository ← Contents: Read and write. תוקף: שנה.
  4. העתק את הטוקן והדבק כאן.
